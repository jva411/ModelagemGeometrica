# Modelagem Geométrica

Este é o projeto de um modelador 3D criado como o trabalho para a cadeira de Modelagem Geométrica da UFC 2025.2.

## Rodando o projeto

Para rodar o projeto você precisa ter instalado no seu ambiente o [Rust + Cargo](https://doc.rust-lang.org/cargo/getting-started/installation.html) e o [Cmake](https://cmake.org/download/) (versão 3.x.y).

Com essas ferramentas, basta rodar `cargo run [--release]` para executar o projeto localmente.
